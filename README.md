# 🎬 Plataforma de Streaming de Vídeos

Projeto de Banco de Dados desenvolvido utilizando **Microsoft SQL Server**, simulando a estrutura de dados de uma plataforma de streaming de vídeos.

## 📌 Sobre o projeto

O projeto foi desenvolvido com o objetivo de aplicar conceitos de modelagem e desenvolvimento de bancos de dados relacionais.

A estrutura simula diferentes áreas de uma plataforma de streaming, incluindo usuários, perfis, assinaturas, pagamentos, dispositivos, conteúdos, gêneros, elenco e histórico de visualizações.

## 🗂️ Estrutura do banco

O banco de dados possui tabelas relacionadas a:

- 👤 Usuários e perfis
- 📱 Dispositivos
- 💳 Planos, assinaturas e pagamentos
- 🎬 Filmes e séries
- 🎭 Elenco
- 🎭 Gêneros
- 📺 Temporadas e episódios
- ▶️ Histórico de visualização
- ⭐ Avaliações
- 📋 Minha lista

## 📊 Consultas desenvolvidas

O projeto também possui consultas para geração de relatórios, incluindo:

### 💰 Relatório financeiro e de assinaturas

Consulta informações de clientes, planos, pagamentos e tempo de assinatura, utilizando múltiplos relacionamentos entre tabelas.

### ⭐ Relatório de avaliações e engajamento

Relaciona conteúdos, gêneros, perfis e avaliações para gerar informações sobre conteúdos com melhores avaliações.
